## Shortcuts that work from any tab

These are Chrome-level shortcuts: they work wherever you are, with nothing open.

| What it does | Mac | Windows / Linux |
|--------------|-----|------------------|
| **Search everything** | ⌘K | Ctrl+Shift+K |
| **AI Assistant** | ⌘J | Ctrl+Shift+J |
| **Jump to a workspace** | ⌥A | Alt+A |
| **Save tab to a workspace** | ⌥D | Alt+D |
| **Next workspace** | not set | not set |
| **Previous workspace** | not set | not set |

<Note>
**Next workspace** and **Previous workspace** ship without keys, so they can't collide with shortcuts you already use. Give them keys yourself in about ten seconds — see [Change or add shortcuts](#change-or-add-shortcuts). Once set, they cycle through your workspace list in order, wrapping around at the end, and each Chrome window cycles its own workspace.
</Note>

<Tip>
You can rebind any of these, so the table above is only the out-of-the-box arrangement. **Settings → Advanced → Keyboard shortcuts** always shows what each command is bound to *right now*, in your own keyboard's notation — and re-reads it the moment you come back from changing one.
</Tip>

## Shortcuts on the dashboard page

These work while the dashboard tab itself is the one you're looking at.

| What it does | Mac | Windows / Linux |
|--------------|-----|------------------|
| **Open the command bar** | ⌘K, or just **/** | Ctrl+K, or just **/** |
| **Show or hide the sidebar** | ⌘B | Ctrl+B |
| **Open the ask bar** | ⌘I | Ctrl+I |
| **Undo the last drop** (while the message is on screen) | ⌘Z | Ctrl+Z |

## What each one does

### Search everything

Opens search over your workspaces, open tabs, saved tabs and saved links. Normally it opens the **side panel** on its Search tab. If the **dashboard** is the tab you're on, it opens the dashboard's [command bar](/help/unscrambled-tabs/ai-and-search#the-command-bar) instead — same search, plus actions you can run by name. On the dashboard you can also just press **/**.

### AI Assistant

Opens the side panel straight onto the chat. See [AI assistant & the command bar](/help/unscrambled-tabs/ai-and-search).

### Jump to a workspace {#jump-to-a-workspace-alta}

Opens the **quick switcher**: your workspaces, most recently used first. Type to filter (workspace or folder names), ↑/↓ to move, **Enter** to switch, **Esc** to close.

The clever bit: the highlight starts on your **previous** workspace, not your current one. So pressing the shortcut then **Enter** flips you straight back to the workspace you were in before — press it again to flip back. It's the fastest way to bounce between two clients all day.

### Save tab to a workspace

Opens a small **Save to workspace** picker: your workspaces grouped by folder, with a search field ready for typing, and a green check on any workspace that already has this page. Choose one and the tab you're on is **saved into it** — **the tab itself stays open**.

To *move* a tab (save it there and close it here), drag it or use the right-click menu — see [Moving tabs](/help/unscrambled-tabs/moving-tabs).

### Undo the last drop

While the **"Moved 1 tab to…"** message is still on screen, **⌘Z** (**Ctrl+Z**) takes the drop back. It never steals ⌘Z from a text box you're typing in. See [Undo](/help/unscrambled-tabs/moving-tabs#undo).

## Change or add shortcuts {#change-or-add-shortcuts}

Chrome owns extension shortcuts, so they're changed in Chrome's own settings:

<Steps>
  <Step title="Open Chrome's shortcut settings">
    Type `chrome://extensions/shortcuts` into the address bar and press Enter. (Or open **Settings → Advanced → Keyboard shortcuts** in the extension and click **Change shortcuts…**, which takes you to the same page.)
  </Step>
  <Step title="Find Unscrambled Tabs">
    Scroll to the **Unscrambled Tabs** section — every command is listed, including the two that ship without keys.
  </Step>
  <Step title="Set your keys">
    Click the pencil next to a command and press the combination you want.
  </Step>
</Steps>

Come back to the extension and **Settings → Advanced → Keyboard shortcuts** will already be showing your new keys.

<Tip>
If a shortcut doesn't seem to do anything, another extension or app may already own that combination — pick a different one on the same settings page.
</Tip>

<Note>
The dashboard shortcuts (**/**, **⌘K**, **⌘B**, **⌘I**, **⌘Z**) belong to the page rather than to Chrome, so they aren't listed at `chrome://extensions/shortcuts` and can't be changed there.
</Note>
