Once you are bouncing between Birdsong Pottery and Marchmont Cafe a dozen times a day, reaching for the mouse starts to grate. This page lists every shortcut, tells you what each one actually opens, and shows you how to change them.

## Shortcuts that work from any tab

These are Chrome-level shortcuts. They work wherever you are, with nothing open.

| What it does | Mac | Windows / Linux |
|--------------|-----|------------------|
| **Search everything** | ⌘K | Ctrl+Shift+K |
| **AI Assistant** | ⌘J | Ctrl+Shift+J |
| **Jump to a workspace** | ⌥A | Alt+A |
| **Save tab to a workspace** | ⌥D | Alt+D |
| **Next workspace** | not set | not set |
| **Previous workspace** | not set | not set |

<Note>
**Next workspace** and **Previous workspace** ship without keys, so they cannot collide with shortcuts you already use. Giving them keys takes about ten seconds. See [Change or add shortcuts](#change-or-add-shortcuts). Once set, they cycle through your workspace list in order and wrap around at the end, and each Chrome window cycles its own workspace.
</Note>

<Tip>
You can rebind any of these, so the table above is only the out-of-the-box arrangement. **Settings → Advanced → Keyboard shortcuts** always shows what each command is bound to right now, in your own keyboard's notation, and it re-reads that the moment you come back from changing one.
</Tip>

## Shortcuts on the dashboard page

These work while the dashboard tab itself is the one you are looking at.

| What it does | Mac | Windows / Linux |
|--------------|-----|------------------|
| **Open the command bar** | ⌘K, or just **/** | Ctrl+K, or just **/** |
| **Show or hide the sidebar** | ⌘B | Ctrl+B |
| **Open the ask bar** | ⌘I | Ctrl+I |
| **Undo the last drop**, while the message is on screen | ⌘Z | Ctrl+Z |

## What each one does

### Search everything

Opens search over your workspaces, open tabs, saved tabs and saved links. Normally it opens the side panel on its Search tab. If the dashboard is the tab you are on, it opens the dashboard's [command bar](/help/unscrambled-tabs/ai-and-search#the-command-bar) instead, which is the same search plus actions you can run by name. On the dashboard you can also just press **/**.

### AI Assistant

Opens the side panel straight onto the chat. See [AI assistant & the command bar](/help/unscrambled-tabs/ai-and-search).

### Jump to a workspace {#jump-to-a-workspace-alta}

Opens the quick switcher: your workspaces, most recently used first. Type to filter on workspace or folder names, use ↑/↓ to move, **Enter** to switch, **Esc** to close.

The useful part is where the highlight starts. It lands on your previous workspace, not your current one, so pressing the shortcut and then **Enter** flips you straight back to the workspace you were in before. Press it again to flip back. It is the fastest way to bounce between two clients all day.

### Save tab to a workspace

Opens a small **Save to workspace** picker: your workspaces grouped by folder, with a search field ready for typing, and a green check on any workspace that already has this page. Choose one and the tab you are on is saved into it. The tab itself stays open.

To move a tab, meaning save it there and close it here, drag it or use the right-click menu. See [Moving tabs](/help/unscrambled-tabs/moving-tabs).

### Undo the last drop

While the **"Moved 1 tab to…"** message is still on screen, **⌘Z** (**Ctrl+Z**) takes the drop back. It never steals ⌘Z from a text box you are typing in. See [Undo](/help/unscrambled-tabs/moving-tabs#undo).

## Change or add shortcuts {#change-or-add-shortcuts}

Chrome owns extension shortcuts, so they are changed in Chrome's own settings:

<Steps>
  <Step title="Open Chrome's shortcut settings">
    Type `chrome://extensions/shortcuts` into the address bar and press Enter. You can also open **Settings → Advanced → Keyboard shortcuts** in the extension and click **Change shortcuts…**, which takes you to the same page.
  </Step>
  <Step title="Find Unscrambled Tabs">
    Scroll to the **Unscrambled Tabs** section. Every command is listed, including the two that ship without keys.
  </Step>
  <Step title="Set your keys">
    Click the pencil next to a command and press the combination you want.
  </Step>
</Steps>

Come back to the extension and **Settings → Advanced → Keyboard shortcuts** will already be showing your new keys.

<Tip>
If a shortcut does not seem to do anything, another extension or app may already own that combination. Pick a different one on the same settings page.
</Tip>

<Note>
The dashboard shortcuts (**/**, **⌘K**, **⌘B**, **⌘I**, **⌘Z**) belong to the page rather than to Chrome, so they are not listed at `chrome://extensions/shortcuts` and cannot be changed there.
</Note>
