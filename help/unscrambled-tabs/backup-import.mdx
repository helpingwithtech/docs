## Export an encrypted backup

Everything you've built — workspaces, folders, resources, settings, and recent [session snapshots](/help/unscrambled-tabs/session-time-travel) — can be saved to a single password-protected file:

<Steps>
  <Step title="Open Settings → Import & Export">
    In the side panel, click the **Settings** gear and find **Import & Export**.
  </Step>
  <Step title="Click Export encrypted backup">
    A dialog asks you to **create a password** (at least 8 characters) and confirm it. Backups are always encrypted — with AES-256-GCM, the kind of encryption banks use — so there's no unprotected copy of your browsing landscape sitting in your Downloads folder.
  </Step>
  <Step title="Click Export & Download">
    A dated file like `unscrambled-tabs-backup-encrypted-2026-07-30.json` lands in your downloads. Store it somewhere safe — cloud drive, USB, or a password manager attachment.
  </Step>
</Steps>

<Warning>
**The password cannot be recovered.** Not by us, not by anyone — that's the point of the encryption. Lose it and the backup can't be opened.
</Warning>

## Restore — a full replace

To restore, drop the backup file onto the **Import** area in **Settings → Import & Export** (or click it to browse). The extension recognises an encrypted backup, asks for your password, and — after **Decrypt & Import** — loads it.

<Warning>
Restoring **replaces** your existing extension data: it's all-or-nothing, by design, for moving machines or disaster recovery. If the current setup matters, export a fresh backup first so you can roll back.
</Warning>

A wrong password gets a clear "Incorrect password" message and nothing is touched.

## Workona import

Coming from Workona? Bring your workspaces with you:

<Steps>
  <Step title="Export from Workona">
    Use Workona's own export to get a `.json` file of your workspaces.
  </Step>
  <Step title="Drop it on the Import area">
    Same dropzone: **Settings → Import & Export → Import**. The extension recognises a Workona export automatically.
  </Step>
  <Step title="Check the result">
    Your Workona workspaces are **added on top of** your existing data — nothing is deleted or replaced (unlike a backup restore). Their saved links arrive grouped into sections in each workspace's [Resources](/help/unscrambled-tabs/workspaces#resources-saved-links).
  </Step>
</Steps>

If a file isn't recognised, you'll see "Unrecognized file format". Check it's a genuine eggz Tab Manager backup or a Workona export.

<Note>
The extension used to be called Unscrambled Tabs. Backups you exported under that name restore exactly as they always did, so there is no need to re-export anything.
</Note>

## What travels and what doesn't

Backups carry your long-lived data: workspaces (tabs, groups, custom names), folders, resources, settings, and snapshots. A few live details — like which window is currently bound to which workspace — belong to the browser session, so after restoring on a new machine just open the side panel and switch to a workspace to get rolling.
