## Drag it where it belongs

Dragging is how tabs get filed. Pick up a tab, drop it on a workspace, and it's saved there. The rules are the same everywhere you can drop, so there's nothing to relearn between the panel and the dashboard.

## What you can pick up

- **An open tab** — any row in the **Open Tabs** list, in the side panel, the floating card, or the dashboard.
- **A saved tab** — any row in a workspace's **Tabs** pane on the dashboard.
- **A saved link** — any row in a workspace's **Resources** pane on the dashboard.

<Tip>
**Several at once.** Hover a row in a tab list and a small square appears where its icon was — click it to start selecting. **⌘-click** (**Ctrl-click** on Windows and Linux) toggles one more row; **Shift-click** takes everything between. Then drag any selected row and the whole selection travels together. **Esc** clears the selection.
</Tip>

## Where you can drop it

| Drop it on | What happens |
|---|---|
| **A workspace** — in the card, the side panel, or the dashboard's open sidebar | The tab is saved into that workspace |
| **A pinned workspace's icon** on the dashboard's slim sidebar | Same thing — no need to open the sidebar first |
| **A folder** | Hold still over the folder for a moment and it opens, then drop on a workspace inside it. (Dropping on the folder itself does nothing — a folder holds workspaces, not tabs.) |
| **The Resources pane**, or one of its named sections (dashboard) | The page is filed as a saved link instead of a tab |

## Move is the default; hold a key to copy

- **Let go normally** and the tab **moves**: it's saved into the workspace you dropped it on, and closed where it was.
- **Hold ⌥ Option** (**Alt** on Windows and Linux) **as you let go** and the tab is **copied**: saved into the workspace *and* left open where it was.

You don't have to remember which one you're getting, because it's written on screen while you drag.

### The label that follows your cursor

From the moment you pick a tab up, a small card follows your cursor. The top line is the page you're carrying. The line underneath tells you exactly what letting go right now would do:

> **Moving 1 tab to Marchmont Cafe — hold ⌥ Option to copy**

Press the key mid-drag and it changes as you watch:

> **Copying 1 tab to Marchmont Cafe — release ⌥ Option to move**

It names the workspace you're hovering, counts what you're carrying, and always spells the key the way your own keyboard does — **⌥ Option** on a Mac, **Alt** on Windows and Linux.

### Prefer copy as the default?

If you'd rather dragging an open tab *kept* it open every time, turn on **Settings → Open Tabs view → Keep the original tab open when dragging to a workspace**. The modifier then does the opposite: hold **⌥ Option** (**Alt**) to move. The label on the card always tells you which way round you are, whichever way you've set it.

This setting is about **open browser tabs** only. Dragging a saved tab or a saved link is unaffected.

## Undo

Every drop can be taken back.

When a drop lands, a message appears in the corner: **"Moved 1 tab to Marchmont Cafe."** with an **Undo** button and the undo shortcut beside it. You have **ten seconds**, and two ways to use them:

- Click **Undo**.
- Press **⌘Z** (**Ctrl+Z** on Windows and Linux).

<Note>
The keyboard shortcut only works while the message is on screen, and it never takes ⌘Z away from a text box — if you're typing in a rename field or the search box, ⌘Z undoes your typing, as it should.
</Note>

The message always counts what really changed. Drop a page into a workspace that already has it and you'll read **"Already in Birdsong Pottery — 1 tab unchanged."** rather than a move that never happened.

### Reopened tabs keep their history

Undoing a **move** puts the tab back where it was — and where Chrome still has the tab in its recently-closed list, it comes back whole: **your back button still works**, and the page is where you left it rather than freshly loaded. If Chrome has already forgotten it, the page is reopened from its address instead, so undo always puts something back.

Undoing a **copy** removes the copy and closes any tab the copy opened.

Either way, a short message confirms it: **"Move undone. 1 tab reopened."**

<Warning>
Undo covers the **last** drop only, and only for ten seconds. It also stays out of the way of anything else you did in the meantime — renaming a workspace or adding a link somewhere else while the message is up is left exactly as you left it.
</Warning>

## Other ways to move a tab

Dragging isn't the only route.

- **Right-click any web page** → **Unscrambled Tabs** → **Move tab to workspace** → pick one. The tab is saved there and closed here. Your most recently used workspaces are listed first (up to 25 of them).
- **On the dashboard, press ⌘K** (**Ctrl+K**) and type *move* → **Move tab to workspace…** → pick one. See [the command bar](/help/unscrambled-tabs/ai-and-search#the-command-bar).
- **To save without closing**, use the **Save tab to a workspace** shortcut (**⌥D** on a Mac, **Alt+D** on Windows and Linux). It opens a small picker; the tab stays open. Or press **⌘K** and type *save*.
